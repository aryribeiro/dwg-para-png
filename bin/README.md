# bin/

- `dwg2dxf` — GNU LibreDWG 0.14, Linux x86_64, ligado estaticamente (não depende de glibc do host). É o que roda no Streamlit Cloud. Compilado com `build/Dockerfile` a partir do tarball oficial da release; sem modificações no código.
- `build/COPYING-LibreDWG` — licença GPL-3.0 do LibreDWG.
- No Windows, coloque aqui `dwg2dxf.exe` (release oficial `libredwg-0.14-win64.zip`); ele fica fora do git.
